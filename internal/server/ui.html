vdl · видео в галерею одним тапом

Self-hosted загрузчик: шорткат на айфоне → видео уже в Фото. Ядро — cobalt, поверх — свои резолверы и куки-менеджер в Telegram.

Шорткат (один раз, 7 действий)
  1. Receive URLs from Share Sheet (вход — только URLs)
  2. If [Shortcut Input] не имеет значения → Show Notification «Нет ссылки» → Stop This Shortcut
  3. Get Contents of URL: https://vdl.0x3654.com/dl?token=<твой_токен>&list=1&url=[Shortcut Input]
  4. Get Dictionary Value → ключ medias
  5. Repeat with Each: внутри — Get Contents of URL [Repeat Item] → Save to Photo Album
  6. После повтора — Show Notification «✓ Сохранено»
  7. В настройках шортката (ⓘ) выключи Show When Run — работает из шаринга молча

Качает всё: видео, картинки, квот-посты (видео из квота), галереи — каждое медиа отдельным файлом в Фото.

Что умеет

Twitter/X (без кук для публичного, NSFW — с куками), YouTube, Instagram, TikTok, Reddit, Bluesky, VK, Rutube и ещё ~20 сервисов через cobalt.

API: GET /dl?token=…&url=… → 302 на видео. Куки аккаунтов — боту @RockyClawdBot в служебной группе: /add, вставь куки, /accounts, /check.

Статус

GET /healthz — живость и число активных куки-аккаунтов. GET /admin/accounts?token=… — список (без секретов).
